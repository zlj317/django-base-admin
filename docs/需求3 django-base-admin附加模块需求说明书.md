## 0. 文档说明

本文档为主系统 `django-base-admin` 的**扩展新增模块**需求，独立于主需求文档整理。所有模块的接口、存储、权限均复用主系统 RBAC 权限体系与统一返回格式；附件统一接入 **kkFileView**（只读预览）与 **OnlyOffice**（在线协同编辑）；报表模块采用 **lowcode-report** 拖拽报表设计器，实时查询基于 **Django Channels + Redis WebSocket**；定时任务基于 **Celery**；大屏模块基于 **datart**。

> **前端 UI 通用规范（菜单层级缩进，全局统一）**：
> 左侧导航菜单，折叠项「工作流程」下的二级子菜单整体向右增加缩进距离，和父菜单「工作流程」形成明显层级区分，视觉上体现父子从属关系；三级子菜单同样整体向右增加缩进距离，和二级子菜单形成明显层级区分，视觉上体现父子从属关系。**该规范适用于系统全部菜单（原有模块 + 本次新增所有模块）统一遵循。**

# 1. 附件管理模块

## 1.1 模块概述

系统统一文件中台，为审批流程、代码生成业务表单、报表模块、公告等全业务提供统一上传、存储、权限、预览、编辑能力。支持本地磁盘存储，预留 MinIO 对象存储扩展适配国产化环境。

> **引擎分工**
> - kkFileView：通用文件只读在线预览（PDF、图片、Office、文本、视频等）
> - OnlyOffice：docx / xlsx / pptx 在线协同编辑，编辑完成回写文件至存储

## 1.2 子菜单

- 附件列表
- 上传配置
- 预览配置
- 附件回收站

## 1.3 功能需求

### 1.3.1 多种上传方式

- 单文件上传、多文件批量上传
- 拖拽上传、截图粘贴上传（Ctrl+V）
- 文件夹上传（浏览器支持）
- 大文件分片上传、断点续传
- 两种模式切换：前端中转后端上传 / 直传存储

### 1.3.2 文件预览与编辑规则

| 文件类型 | 处理方式 |
| --- | --- |
| 图片（jpg/png/gif/webp/svg） | 预览支持缩放、旋转 |
| PDF、txt、md、json、xml、sql | kkFileView 预览 |
| Office 文档（docx/xlsx/pptx） | 查看：kkFileView 只读预览；编辑：跳转 OnlyOffice 在线编辑，支持多人协同，保存后覆盖原文件或生成新版本 |
| 音视频（mp4/mp3） | 在线播放预览 |
| 压缩包 zip | 解析内部文件目录列表预览，不可在线解压 |
| 不支持预览的文件 | 仅提供下载按钮 |

### 1.3.3 文件管理能力

- MD5 校验去重，相同文件只存一份；
- 业务关联绑定：关联业务类型、业务 ID（审批单、报表、单据等）；
- 权限控制：公共附件、私有附件、业务绑定附件隔离；归档锁定附件禁止删除；
- 预览水印：可配置开启图片、PDF 自动添加用户名 + 时间水印；
- 文件有效期：临时附件支持自动过期清理；
- 回收站软删除，支持恢复、彻底删除；
- 全操作日志：上传、预览、下载、编辑、删除、恢复记录。

### 1.3.4 配置项

- 文件后缀白名单、单文件大小上限、分片大小；
- 存储策略：本地 / MinIO 切换；
- kkFileView 服务地址、OnlyOffice 服务地址配置；
- 水印开关、过期清理周期配置。

## 1.4 接口清单（DRF）

- 上传接口、分片上传初始化、分片合并接口；
- 文件列表分页查询、详情查询；
- 获取预览地址、获取 OnlyOffice 编辑地址；
- 文件删除、回收站列表、恢复、永久删除；
- 配置查询、配置保存；
- 文件打包批量下载接口。

## 1.5 联动其他模块

- 工作流审批表单、代码生成页面、报表模块直接调用上传组件；
- 报表生成的 PDF/Excel 自动存入附件管理；
- 消息、公告可关联附件。

# 2. 消息中心模块

## 2.1 模块概述

统一站内消息推送平台，承接审批待办、抄送、流程超时、报表生成结果、系统告警、公告提醒，前端右上角消息红点提醒，预留短信、邮件推送扩展。

## 2.2 子菜单

- 消息模板
- 站内消息
- 消息推送记录
- 推送配置

## 2.3 功能需求

- 消息模板管理：定义模板内容、变量占位符（发起人、单据标题、链接）；
- 消息类型：待办审批、已办通知、抄送通知、系统通知、报表任务通知、告警消息；
- 消息已读 / 未读标记、全部已读、删除消息；
- 推送记录：记录推送状态、失败重试；
- 推送渠道开关：站内信、短信、邮件；
- 前端实时消息推送（WebSocket），右上角未读数量红点。

## 2.4 联动

- SpiffWorkflow 审批节点自动触发待办消息；
- Celery 定时任务执行失败、报表生成完成自动推送通知。

# 4. 定时任务管理模块

## 4.1 模块概述

可视化管理 Celery 定时任务，统一调度后台异步任务。

## 4.2 子菜单

- 任务列表
- 任务日志

## 4.3 功能需求

- 任务新增、编辑、启停、删除、立即执行一次；
- 支持 cron 表达式、间隔定时两种调度模式；
- 任务执行日志：状态、返回信息、异常报错、耗时；
- 失败任务自动重试配置。

## 4.4 内置预置任务

- 过期附件自动清理；
- BPMN 流程超时节点检测；
- 报表模板定时生成报表文件；
- 消息推送重试任务。

## 4.5 联动

报表管理定时生成任务注册到此模块；任务执行结果推送消息告警。

# 5. 报表管理模块

## 5.1 模块概述

拖拽式低代码报表平台，基于 **lowcode-report** 前端报表引擎，支持业务人员可视化设计中国式报表、分组、交叉报表、参数报表，支持手动 / 定时生成报表，报表文件存入附件管理。

## 5.2 子菜单（与截图保持一致）

- 报表设计
- 报表生成
- 报表查询
- 报表实时查询

## 5.3 功能需求

### 5.3.1 报表设计

- 拖拽画布设计报表模板，支持单元格合并、表达式、变量参数、数据过滤、分组、小计、合计、交叉表；
- 数据源配置：支持本系统 MySQL 数据源、外部 API 数据源（复用【数据同步/外部对接】模块接口）；
- 报表样式配置、页眉页脚、水印、打印模板配置；
- 模板版本管理、模板权限控制（不同角色只能编辑/查看指定报表）；
- 保存报表 JSON 模板到数据库。

### 5.3.2 报表生成

- 手动触发报表生成、定时调度生成（对接 Celery 定时任务）；
- 传入报表参数，后台执行数据源查询、渲染报表；
- 生成 Excel/PDF 文件，自动存入附件管理；
- 生成记录、生成日志、异常失败告警、重试机制。

### 5.3.3 报表查询

- 报表模板列表，按参数条件查询历史生成的报表文件；
- 在线预览（kkFileView）、下载、分享、权限控制；
- 支持批量导出、打包下载。

### 5.3.4 报表实时查询

- 基于 WebSocket 实时数据推送（Django Channels + Redis）；
- 指标报表实时刷新，支持阈值告警标记；
- 适合业务实时统计、流程待办数量、单据实时统计。

## 5.4 联动规则

- 报表生成后的文件自动存入附件管理，复用附件权限、预览、下载能力；
- 报表数据源可选择外部接口，复用【数据同步/外部对接】已配置的接口；
- 报表定时生成任务注册到【定时任务】模块统一管理；
- 报表生成完成、报表异常消息推送至【消息中心】；
- 报表导出的 Office 文档，支持跳转 OnlyOffice 在线编辑。

## 7.1 模块概述

统一外部接口管理平台，管理第三方系统对接配置、请求日志，给报表、大屏、业务流程提供外部数据源能力。

## 7.2 子菜单

- 接口配置
- 请求日志
- 数据同步任务

## 7.3 功能需求

- 接口新增编辑：地址、请求方式、请求头、参数、认证方式（Token、BasicAuth）；
- 接口连通性测试；
- 同步任务配置：定时拉取外部数据写入本地库；
- 完整请求日志：入参、返回结果、耗时、状态码、异常信息；

## 7.4 联动

为报表管理、报表大屏提供外部 API 数据源；同步任务注册到定时任务模块调度。

# 8. 前端 UI 通用规范（菜单层级缩进，全局统一）

> 适用于系统全部一级、二级、三级导航菜单（原有模块 + 本次新增所有模块）。

1. **一级菜单**：基础缩进，无额外偏移；
2. **二级子菜单**：相比父一级折叠菜单，**整体向右增加缩进**，形成明显视觉区分，体现父子从属关系；
3. **三级子菜单**：相比所属二级菜单，**继续向右增加缩进**，和二级菜单拉开层级距离；
4. **示例结构**：

```
└── 工作流程（一级折叠菜单，基础缩进）
    ├── 流程管理（二级，向右缩进）
    │   └── 流程模型（三级，在二级基础上继续向右缩进）
    ├── 审批中心（二级，向右缩进）
    │   ├── 待办任务（三级，继续向右缩进）
    │   └── 已办任务（三级，继续向右缩进）
    └── OA示例（二级，向右缩进）
```

5. **要求**：所有菜单层级统一缩进值，样式保持一致；折叠展开时缩进布局不变形。
