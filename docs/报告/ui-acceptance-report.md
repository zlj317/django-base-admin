**判定**

- 10/10 组合主色一致写入 `--el-color-primary` / `--brand-primary` / `--chart-1`，三处无偏差。

- `html.dark` 与 `body[arco-theme]` 双标记同步，保证 Element Plus 与 Arco 同时进入暗色。

**图表跟随（附加验证）**：青绿主题下首页迷你走势线 `stroke` 实测为 `rgb(15,198,194)`，与 `--chart-1` 完全一致，说明 SVG 属性已改为变量引用而非硬编码。

## 十、遗留问题与风险

| 级别 | 项 | 影响 | 建议 |
| --- | --- | --- | --- |
| 中 | 主 JS 1.32 MB / CSS 790 kB | 冷启动偏慢 | `manualChunks` 拆分 Element Plus、bpmn-js；Arco 改按需 CSS |
| 低 | Arco 仅用于主题面板 | 组件栈双轨 | 若要整站迁移需分批替换并回归权限 |
| 低 | 查询区未做折叠展开 | 条件多的页面略占高度 | 封装折叠查询容器 |
| 低 | 表格无骨架屏 | 首屏为 loading 遮罩 | 增加骨架行 |
| 低 | 长表单仍为弹窗 | 字段多时滚动较长 | 超 12 字段改抽屉/分步 |
| 低 | `bi/screen/view.vue` 自带全屏暗色 | 不随明暗切换 | 视为独立展示页，或增加「大屏主题」开关 |

## 十一、验收结论

1. 本轮 UI 优化**满足验收标准**：改造覆盖列表、表单、弹窗、详情、全局框架与登录/首页，且未改动任何后端逻辑、接口契约、权限规则与路由机制。
2. 主题系统**可交付**：5 套主题色 × 明暗 2 模式全部实测生效，顶栏可切换、localStorage 持久化、刷新保持、图表与组件同步。
3. 生产构建**可发布**：`npm run build` 成功，无编译错误；仅有体积优化建议，不构成阻断。
4. 建议后续按「遗留问题」优先级处理体积拆分与组件栈统一，其余项为体验增强，不影响当前验收结论。
