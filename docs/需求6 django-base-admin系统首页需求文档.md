## 0. 文档说明

本文档基于系统已实现的全部功能模块，重新设计登录后的**系统首页（工作台）**展示内容。原首页仅展示欢迎横幅、4 个快捷入口、系统简介与使用流程，信息量不足。新首页作为**用户工作入口与数据总览台**，整合所有已有模块的动态数据、待办任务、快捷入口、监控与报表概览，并按用户权限动态渲染。

> 设计原则：首页只做「概览与入口」，不承载业务操作；所有数据均来自各业务模块实时接口，随权限过滤，无权限模块不展示。

## 3. 首页区块详细需求

### 3.1 顶部欢迎横幅

| 项 | 说明 |
| --- | --- |
| 问候语 | 按时间段显示：早上好/中午好/下午好/晚上好，+ 用户名 + “欢迎回来” |
| 副语 | 动态文案，如“今天也是充满效率的一天~” |
| 日期时间 | 实时显示当前日期、星期、时间（前端时钟） |
| 技术栈标识 | 右上角展示 Django · Vue3 · MySQL（可扩展 Element Plus、Vite） |
| 其他 | 可选显示当前天气、登录 IP、最近登录时间 |

### 3.2 核心数据统计卡片

一行横向卡片，每卡含：图标、数字、名称、趋势（可选），点击跳转对应模块。**按当前用户权限动态显示**。

| 卡片 | 数据来源 | 跳转 |
| --- | --- | --- |
| 用户总数 | sys_user 统计 | 系统管理-用户管理 |
| 角色总数 | sys_role 统计 | 系统管理-角色管理 |
| 菜单/权限数 | sys_menu 统计 | 系统管理-菜单管理 |
| 我的待办 | wf_task 待办数 | 审批中心-待办任务 |
| 流程实例 | wf_instance 我发起的 | 审批中心-我的流程 |
| 附件总数 | wf_file 统计 | 附件管理-附件列表 |
| 报表数量 | rp_template / rp_generate_record | 报表管理-报表查询 |
| 公告数 | notice_info 未读 | 公告通知 |
| 未读消息 | msg_record 未读 | 消息中心 |
| 工单待办 | work_order 待处理 | 工单管理 |

> 权限控制：无对应菜单权限的用户不显示该卡片；全部无权限时隐藏该区块。

### 3.3 左侧用户工作区

- 用户头像、昵称、所属部门、角色标签；
- 今日日程：展示当天 cal_schedule 日程列表（时间+标题），点击跳转日历日程；
- 常用功能：最近访问 / 收藏的常用模块入口（个人偏好，本地缓存）。

### 3.4 待办工作台

以 Tab 形式聚合用户所有待处理事项：

| Tab | 内容 | 数据来源 |
| --- | --- | --- |
| 审批待办 | 审批中心待办任务：标题、发起人、节点、时间，点击跳转处理 | wf_task |
| 工单待办 | 分派给我的未处理工单：工单号、标题、优先级、时间 | work_order |
| 日程提醒 | 今天及即将到期的日程提醒 | cal_schedule / cal_reminder |
| 消息通知 | 未读消息、待处理告警 | msg_record / monitor_alarm_record |

> 每条展示最新 5~10 条，支持“查看全部”跳转对应模块；无数据时显示空状态友好提示。

### 3.5 消息与公告区

- 最新公告：展示最近 3~5 条已发布公告（标题 + 发布时间 + 置顶标记），点击查看详情；
- 最新消息：展示最近消息（类型图标 + 标题 + 时间），未读高亮，支持“全部已读”；
- 若系统启用推送，红点角标同步待办数量。

### 3.6 系统监控面板

面向管理员（无权限则隐藏），展示实时运行状态：

| 监控项 | 内容 |
| --- | --- |
| 服务状态 | Django 服务在线状态、uptime |
| 数据库 | MySQL 连接状态、连接数 |
| 缓存 | Redis 连接状态、内存使用 |
| 存储 | 磁盘使用率、附件存储占用 |
| 定时任务 | 今日执行成功/失败数，失败高亮 |
| 外部接口 | 数据同步/外部对接近期请求成功率 |

> 点击各监控项跳转【系统管理-监控告警】详情；异常状态红色告警提示。

### 3.7 快捷功能入口

以卡片网格形式覆盖全部已有模块，**按权限动态显示**。分 2~3 行，每行 4~6 个卡片：

| 分组 | 快捷入口 |
| --- | --- |
| 系统管理 | 用户管理、角色管理、菜单管理、部门管理、字典管理、参数配置 |
| 代码生成 | 数据表管理、生成配置 |
| 工作流程 | 发起流程、我的流程、待办任务、已办任务 |
| 附件与报表 | 附件管理、报表设计、报表查询、报表大屏 |
| 其他 | 消息中心、公告通知、定时任务、工单管理、日历日程、知识库 |

> 卡片包含：图标、名称、一行简短说明（如“账号与角色分配”“一键生成前后端”）；点击跳转对应路由。超过权限范围的入口不显示。

### 3.8 数据图表区

基于报表/大屏模块，展示可视化概览图表（按权限）：

| 图表 | 说明 |
| --- | --- |
| 审批趋势图 | 近 7 天/30 天发起、通过、驳回数量趋势（折线/柱状） |
| 单据分类统计 | 各类流程实例占比（饼图） |
| 附件类型分布 | 上传文件类型占比（饼图/柱状） |
| 工单状态统计 | 待处理/处理中/已解决/已关闭数量（柱状） |

> 图表数据来自各业务模块统计接口；点击图表跳转对应报表/大屏详情页。

### 3.9 系统简介与使用流程

保留原板块并扩展：

- **系统简介**：展示系统功能模块说明与代码生成能力介绍，技术标签（Django、Vue3、Element Plus、MySQL、Vite，可加 Redis、Celery、kkFileView）；
- **使用流程**：分步说明代码生成操作步骤（选择业务表 → 配置字段 → 预览下载 → 自动注册菜单），保留三步核心流程；
- 新增「快速开始」引导：未使用过代码生成的用户展示引导提示，点击直达代码生成器。

## 4. 接口清单（首页聚合接口）

> 首页采用聚合接口一次性返回，减少前端多次请求。

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| /home/overview | GET | 聚合返回：问候、统计卡片、待办、消息、公告、监控、图表数据、快捷入口（按权限） |
| /home/statistics | GET | 仅核心统计数字 |
| /home/todos | GET | 待办工作台各 Tab 数据 |
| /home/monitor | GET | 监控面板状态 |
| /home/charts | GET | 图表数据 |
| /home/favorites | POST | 保存用户常用功能收藏 |

> 返回体统一 `{code, msg, data}`；所有数据按当前登录用户 RBAC 权限过滤。

## 5. 权限与交互规则

1. **权限驱动**：首页所有区块（统计、快捷入口、待办、监控、图表）按当前用户权限动态显示，无权限内容不渲染、不请求对应数据；
2. **数据实时性**：统计数字、待办、消息进入首页时实时刷新；图表支持定时轮询或手动刷新；
3. **消息红点**：顶部导航栏消息、待办数量红点角标与首页联动；
4. **交互**：所有卡片、入口、待办项均可点击跳转对应模块；空数据展示友好空状态；监控异常红色告警；
5. **加载**：首页骨架屏加载，聚合接口失败时分区降级（某区块失败不影响其他区块）。

## 6. 视觉与布局规范

- 延续系统蓝紫渐变顶部导航 + 浅白底布局（与现首页一致）；
- 卡片圆角、阴影统一（圆角 12px、阴影 `0 2px 12px rgba(0,0,0,0.06)`）；
- 统计卡片图标底色分区色块，数字加粗突出；
- 整体栅格自适应，1920 分辨率默认 4~6 列，1280 分辨率自动降列；
- 遵循全局菜单层级缩进 UI 规范。

## 8. 需求摘要（可写入文档头部）

> 系统首页由原「欢迎横幅 + 4 快捷入口 + 简介 + 流程」升级为**统一工作台**，整合系统全部功能模块：顶部欢迎横幅、核心数据统计卡片（用户/待办/流程/附件/报表/公告/未读等）、左侧用户工作区（今日日程/常用功能）、待办工作台（审批/工单/日程/消息四 Tab）、消息与公告区、系统监控面板（服务/数据库/Redis/磁盘/任务/外部接口）、快捷功能入口网格（覆盖全部模块）、数据图表区（审批趋势/分类占比）以及系统简介与使用流程；全部区块按 RBAC 权限动态渲染，采用聚合接口一次加载，点击即跳转对应模块，作为日常工作的统一入口与数据总览台。
