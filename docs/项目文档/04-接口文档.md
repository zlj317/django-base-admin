## 1. 通用约定

### 1.1 基础信息

| 项 | 说明 |
|---|---|
| Base URL | `http://127.0.0.1:8000` |
| 开发代理 | `http://localhost:5173/api/**` → `127.0.0.1:8000` |
| 数据格式 | `application/json`（上传为 `multipart/form-data`） |
| 字符编码 | UTF-8 |
| 时间格式 | `yyyy-MM-dd HH:mm:ss` |
| 主键 | 雪花 `BIGINT`，响应中自动转为字符串 |

### 1.2 认证

除登录与 3D 分享接口外，均需携带：

```
Authorization: Bearer <token>
```

- Token 有效期 2 小时；
- 剩余不足 30 分钟时，响应头返回 `X-Refresh-Token`，前端替换本地 token；
- 401 表示未登录/过期；403 表示已登录但缺少权限，`msg` 会带缺少的权限标识。

### 1.3 统一响应

HTTP 状态恒为 200，业务结果由 `code` 表达：

```json
{
  "code": 200,
  "msg": "success",
  "data": {}
}
```

| code | 含义 |
|---|---|
| 200 | 成功 |
| 400 | 参数校验失败 / 业务前置条件不满足 |
| 401 | 未登录或 token 无效/过期 |
| 403 | 无操作权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

### 1.4 列表、分页与查询

请求参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `page` | 1 | 页码 |
| `page_size` | 10 | 每页条数 |
| 业务参数 | — | 各 ViewSet 的 `filter_map`，如 `name`（模糊）、`status`（精确） |

分页响应：

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "list": [],
    "total": 0,
    "page": 1,
    "page_size": 10
  }
}
```

### 1.5 标准 CRUD 模板

除 `/api/gen/`、`/api/wf/`、`/api/home/`、`/api/scene3d/` 的特殊动作外，各资源均遵循：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/{资源}/list` | 分页列表 |
| POST | `/{资源}/create` | 新增（部分模块与 `list` 共用入口） |
| PUT | `/{资源}/update/<pk>` | 按主键更新 |
| DELETE | `/{资源}/delete` | 批量逻辑删除（body 传 `ids` 时批量，传 `id` 时单条） |

> 下文只列「资源前缀 + 自定义动作」，未列出的均按上述模板。

## 2. 认证接口

前缀 `/api/auth/`（`apps/system/urls_auth.py`）。

| 方法 | 路径 | 说明 | 登录 |
|---|---|---|---|
| POST | `/api/auth/login` | 登录，返回 token/user/perms/menus | 否 |
| GET | `/api/auth/userinfo` | 当前用户信息 | 是 |
| POST / DELETE | `/api/auth/logout` | 退出登录 | 是 |

登录请求：

```json
{ "username": "admin", "password": "123456" }
```

登录响应 `data`：

```json
{
  "token": "<JWT>",
  "user": { "id": "…", "username": "admin", "nickname": "超级管理员", "avatar": null },
  "perms": ["*:*:*"],
  "menus": []
}
```

## 11. 3D 可视化 `/api/scene3d/`

### 11.1 资源与自定义动作

| 资源 | 自定义动作 |
|---|---|
| `category` | `PUT /category/update/<pk>/status` |
| `template` | `PUT /template/update/<pk>/status` |
| 场景（无前缀） | `GET /<pk>/detail`、`POST /<pk>/save`、`POST /<pk>/publish`、`POST /<pk>/offline`、`POST /<pk>/copy`、`GET /<pk>/versions`、`POST /<pk>/rollback`、`POST /<pk>/share`、`GET /<pk>/visit-log`、`GET /<pk>/export` |
| `model` | `POST /model/upload`、`GET /model/<pk>/preview` |
| `object` | 标准 CRUD |
| `binding` | `GET /binding/<pk>/preview` |
| `alarm/rule` | 标准 CRUD |
| `alarm` | `GET /alarm/records`、`POST /alarm/<pk>/confirm`、`GET /alarm/stats` |
| `route` | `POST /route/<pk>/play` |
| `route/record` | 标准 CRUD（只读为主） |
| `permission` | 标准 CRUD |
| `visit-log` | 标准 CRUD |
| 大屏 | `GET /api/scene3d/screen/data` |
| 分享 | `GET /api/scene3d/share/<token>`（免登录） |

### 11.2 保存场景请求

```json
{
  "objects": [
    { "id": "…", "object_name": "机柜A", "model_id": "…", "position_x": 0, "position_y": 0, "position_z": 0, "rotation_y": 0, "scale": 1 }
  ],
  "bindings": [
    { "object_id": "…", "bind_type": "table", "bind_key": "temperature", "min_value": 0, "max_value": 100 }
  ]
}
```

### 11.3 发布校验

- 场景必须至少 1 个对象，否则返回 `code=400, msg="场景暂无对象，无法发布"`；
- 对象引用的模型资源必须存在且 `status=1`；
- 发布成功写入 `scene3d_scene_version`，场景状态置为已发布。

### 11.4 分享

`POST /api/scene3d/<pk>/share` 请求：

```json
{ "expire_days": 7 }
```

- 仅已发布场景可分享，`expire_days` 限制 1~30；
- 返回 `share_token` 与 `share_url`；
- 分享接口 `GET /api/scene3d/share/<token>` 免登录，校验有效期并写 `scene3d_access_log`。

## 12. 错误码与调试

### 12.1 常见业务提示

| code | 场景示例 |
|---|---|
| 400 | 用户名或密码错误；场景暂无对象，无法发布；分享天数需在 1~30 之间 |
| 401 | 未登录、token 已过期 |
| 403 | 没有操作权限：`system:user:create` |
| 404 | 用户不存在、场景不存在、分享链接无效或已过期 |
| 500 | 服务器内部错误（响应会带异常信息，便于联调） |

### 12.2 调试建议

```bash
# 登录并提取 token（PowerShell）
$r = Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/api/auth/login `
  -ContentType 'application/json' -Body '{"username":"admin","password":"123456"}'
$token = $r.data.token

# 带 token 查询用户列表
Invoke-RestMethod -Uri 'http://127.0.0.1:8000/api/system/user/list?page=1&page_size=10' `
  -Headers @{ Authorization = "Bearer $token" }
```

- 所有写操作会自动写入 `sys_oper_log`，可用操作日志页面核对入参/出参/耗时；
- 文件上传失败先看 `wf_file_config` 的大小与后缀白名单；
- 3D 上传失败检查 `model` 资源白名单与 50MB 限制。
