### 2.3 回归脚本约定

- 使用 `Invoke-RestMethod` / `requests` 发真实请求；
- 每个写操作生成 `test_<时间戳>` 前缀数据；
- 回归结束执行逻辑删除并核对列表数量；
- 失败项立即输出「接口 + 入参 + 响应体」，便于定位。

| 安全渗透测试 | 未覆盖 | 仅做基础登录/越权校验 |
| 多租户数据隔离 | 未覆盖 | 表与页面齐全，隔离策略未做端到端验证 |
