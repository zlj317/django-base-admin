## 1. 架构与工程

| 术语 | 英文/缩写 | 解释 |
|---|---|---|
| 前后端分离 | SPA + REST | 前端 Vue 单页应用，后端仅提供 `/api/**` JSON 接口 |
| App | Django App | 后端按业务域拆分的应用包，位于 `backend/apps/*`，共 25 个 |
| 基座 | Common | `backend/common` 公共能力：JWT、权限、分页、响应、异常、中间件、雪花 ID |
| SQL-first | — | 表结构以 `docs/*.sql` 为唯一来源，模型 `managed=False`，不走 Django Migration |
| 代码生成器 | Code Generator | 读取物理表 → 生成模型/序列化器/视图/路由/前端页面 → 下载 ZIP 并注册菜单 |
| 种子数据 | Seed | `init_db` 调用各应用 `seed_*()` 写入菜单、按钮权限与演示数据 |
| 幂等 | Idempotent | `init_db` 可重复执行：建表 `IF NOT EXISTS`、菜单已存在跳过 |

## 2. 认证与权限

| 术语 | 英文/缩写 | 解释 |
|---|---|---|
| JWT | JSON Web Token | 无状态令牌，HS256 签名，有效期 2 小时 |
| 静默续期 | Token Refresh | 剩余有效期 < 30 分钟时，响应头 `X-Refresh-Token` 下发新 token |
| bcrypt | — | 密码哈希算法，存储与校验均使用 bcrypt |
| RBAC | Role-Based Access Control | 用户 → 角色 → 菜单/按钮权限 |
| 权限标识 | perms | 形如 `system:user:create`、`scene3d:scene:publish` 的字符串 |
| 超管通配 | `*:*:*` | `admin` 角色的通配权限，跳过逐项校验 |
| 按钮权限 | F 类型菜单 | `menu_type=F`，控制页面内按钮显隐与接口调用 |
| 数据权限 | Row-level Permission | 按「本部门/含下级/仅本人/自定义 SQL」限制可查数据范围 |
| 字段脱敏 | Desensitization | 对手机号、身份证等字段按规则掩码展示，可绑定角色 |
| 多租户 | Multi-tenant | 一套系统服务多个租户，通过 `sys_tenant*` 表管理 |

## 3. 数据与接口

| 术语 | 英文/缩写 | 解释 |
|---|---|---|
| 雪花 ID | Snowflake ID | 分布式自增 BIGINT 主键，前端以字符串接收避免精度丢失 |
| 逻辑删除 | Soft Delete | `is_deleted=1` 标记删除，数据保留，可恢复 |
| 审计字段 | Audit Fields | `create_by/create_time/update_by/update_time` |
| 统一响应 | Uniform Response | `{code, msg, data}`，HTTP 状态恒为 200 |
| 业务码 | Business Code | body 中的 `code`：200/400/401/403/404/500 |
| 分页 | Pagination | `page/page_size`，响应含 `list/total/page/page_size` |
| 过滤器 | filter_map | ViewSet 声明的「查询参数 → ORM lookup」映射，如 `icontains`、`exact` |
| 序列化器 | Serializer | DRF 组件，负责模型 ↔ JSON 转换与字段校验 |
| 视图集 | ViewSet | DRF 组件，按 action 映射到 list/create/update/delete 等方法 |
| 基础平台表 | sys_* | 用户、角色、菜单、部门、字典、参数、日志等 |
| 附加模块表 | wf_/msg_/notice_/... | 附件、消息、公告、任务、报表、BI、外部对接 |
| 增强功能表 | 33 张 | 编码规则、导入打印、备份、数据权限、脱敏、监控、安全、租户、工单、日程、知识库 |
| 3D 表 | scene3d_* | 场景、模型、对象、绑定、告警、巡检、版本、授权、访问日志 |

## 4. 工作流

| 术语 | 英文/缩写 | 解释 |
|---|---|---|
| BPMN | Business Process Model and Notation | 业务流程建模标准，前端 bpmn-js 绘制，后端 Python 解析 |
| 流程模型 | Model | 可发布的流程定义，包含节点、连线、审批人规则 |
| 流程实例 | Instance | 一次具体发起，记录 `model_version`，不受后续模型修改影响 |
| 任务 | Task | 实例中的一个待办节点，状态：待处理/已完成/已转办等 |
| 审批轨迹 | Trace | `wf_audit` 记录的节点流转与意见 |
| 会签 | Countersign | 多人同时审批，按比例或全部通过才流转 |
| 或签 | Or-sign | 多人中任意一人处理即可流转 |
| 加签 | Add Sign | 在当前节点临时增加审批人（如前加签/后加签） |
| 转审 | Transfer | 把当前任务转交他人处理 |
| 退回 | Back | 退回上一节点或指定节点 |
| 撤回 | Withdraw | 发起人在无人处理前撤销实例 |
| 抄送 | CC | 把流程进展通知给非审批人 |

## 5. 3D 可视化

| 术语 | 英文/缩写 | 解释 |
|---|---|---|
| 数字孪生 | Digital Twin | 用 3D 场景映射真实机房/设备，并叠加实时数据 |
| 场景 | Scene | `scene3d_scene`，3D 可视化的一级业务对象 |
| 场景分类 | Category | 场景归类，便于检索与授权 |
| 场景模板 | Template | 新建场景时可复用的初始配置 |
| 场景对象 | Object | 场景中的具体设备实例（机柜、服务器、空调、UPS 等） |
| 模型资源 | Model Resource | 可复用的 GLTF/GLB 等模型文件及贴图 |
| 数据绑定 | Data Binding | 对象属性与表字段/API 数据点关联，用于着色与读数 |
| 告警联动 | Alarm Linkage | 数据超过阈值时生成告警记录并在场景中高亮 |
| 巡检路线 | Patrol Route | 以多个点位组成的相机漫游路径，可生成巡检记录 |
| 场景版本 | Version | 每次发布生成快照，可回滚 |
| 场景授权 | Permission | 指定用户/角色对场景的只读或编辑权限 |
| 分享 Token | Share Token | 已发布场景生成的免登录访问凭证，有效期 1~30 天 |
| 只读查看 | Read-only View | 不进入编辑器，仅浏览场景的页面 |
| 大屏模式 | Screen Mode | 聚合场景、告警、巡检等数据的展示页 |

## 6. 前端与主题

| 术语 | 英文/缩写 | 解释 |
|---|---|---|
| 设计令牌 | Design Token | `--app-*`、`--brand-*`、`--chart-*` 等 CSS 变量，统一换肤 |
| 明暗模式 | Light / Dark | 两套表面与文本令牌，持久化到 `localStorage` |
| 主题色 | Brand Color | 5 套：深海蓝、青碧绿、幻夜紫、活力橙、玫瑰红 |
| 动态路由 | Dynamic Route | 登录后按后端 `menus` 注册路由 |
| 引导卡 | Empty Guide | 无数据时展示用途说明与跳转入口，不使用 mock |
| 独立 chunk | Code Splitting | three.js 等大依赖按需加载，避免拖慢首屏 |
| 视觉回归 | Visual Regression | 指定视口与主题下截图核对布局与配色 |

## 7. 运维与质量

| 术语 | 英文/缩写 | 解释 |
|---|---|---|
| 接口回归 | API Regression | 脚本化真实 HTTP 请求覆盖主链路，本轮 250 项 |
| 浏览器巡检 | Browser Inspection | 在 1440/1280 视口逐页检查布局、主题与控制台 |
| 演示/预留 | Demo / Reserved | 表与页面真实存在，但未接入真实外部服务（调度、推送、备份、预览等） |
| 幂等脚本 | Idempotent Script | 可重复执行不产生重复数据的 SQL / 命令 |
| 逻辑备份 | Logical Backup | `mysqldump` 导出 SQL 文本 |
| 回滚点 | Rollback Point | 发布前记录的代码版本 + 数据库备份时间点 |
| 验收清单 | Acceptance Checklist | 交付前逐项确认的功能与质量清单 |
