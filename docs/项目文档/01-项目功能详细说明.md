## 1. 系统定位与总体能力

一个 SQL-first 的后台管理系统：表结构由 `docs/*.sql` 手工维护，Django 模型 `managed=False`；后端提供统一 REST 接口，前端由后端菜单树驱动动态路由。

| 能力域 | 内容 |
|---|---|
| 平台基座 | JWT 认证、RBAC 菜单/按钮权限、用户/角色/部门/字典/参数/日志 |
| 生产力工具 | 代码生成器（读表 → 配置 → 预览 → 下载 → 注册菜单）、BPMN 工作流 |
| 业务协作 | 附件、消息、公告、定时任务、报表、BI 大屏、外部对接 |
| 通用标配 | 编码规则、导入/打印模板、数据备份、数据权限、字段脱敏、监控告警、安全策略 |
| 高级可选 | 多租户、工单、日历日程、知识库 |
| 展示层 | 首页 Dashboard（真实数据聚合）、3D 可视化/数字孪生 |
| 工程约定 | `{code, msg, data}` 统一响应、雪花主键、逻辑删除、操作日志、Token 静默续期 |

- 后端 App 数量：**24 个**（`backend/apps/` 下的业务应用，`backend/config/settings.py` 的 `INSTALLED_APPS` 全部注册）。
- 数据表数量：**92 张**（5 个 SQL 脚本，详见 [数据库设计与数据字典](./05-数据库设计与数据字典.md)）。
- 前端页面目录：`frontend/src/views/` 下 26 个分组目录，覆盖全部菜单页面与隐藏页。

## 2. 技术架构

| 层 | 实际实现 | 位置 |
|---|---|---|
| 前端 | Vue 3 + Vite 5 + Element Plus + vue-router 4 + axios | `frontend/` |
| 主题 | CSS 设计令牌 + 明暗模式 + 5 套主色 | `frontend/src/styles/tokens.css`、`frontend/src/theme/` |
| 接入 | 开发期 Vite proxy（5173 → 8000）；生产 Nginx | `frontend/vite.config.js` |
| 认证 | 自研 JWT（HS256，2 小时，剩余 30 分钟静默续期）+ bcrypt | `backend/common/auth.py` |
| 权限 | `PermissionCheck` + 前端 `v-perm`；`admin` 拥有 `*:*:*` | `backend/common/permissions.py` |
| 响应 | `{code, msg, data}`，HTTP 状态恒 200；雪花 ID 自动转字符串 | `backend/common/response.py` |
| 数据 | MySQL 8 + PyMySQL/mysqlclient，SQL-first，`managed=False` | `backend/config/settings.py`、`docs/*.sql` |
| 3D | three.js 动态 import，独立 chunk | `frontend/src/components/SceneViewer`、`views/scene3d/` |

## 3. 平台基础模块

对应后端 `apps/system`，接口前缀 `/api/system/` 与 `/api/auth/`。

| 功能 | 页面组件 | 关键接口 | 说明 |
|---|---|---|---|
| 登录/登出/当前用户 | `login/index.vue` | `POST /api/auth/login`、`GET /api/auth/userinfo`、`POST|DELETE /api/auth/logout` | 返回 token、user、perms、menus |
| 用户管理 | `system/user/index.vue` | `/api/system/user/{list,create,update/<pk>,delete}` + `reset_pwd`、`status`、`assign_roles` | 角色分配、重置密码、启停 |
| 角色管理 | `system/role/index.vue` | `/api/system/role/*` + `menu_ids`、`assign_menus` | 菜单授权 |
| 菜单管理 | `system/menu/index.vue` | `/api/system/menu/*` + `tree` | M 目录 / C 页面 / F 按钮 |
| 部门管理 | `system/dept/index.vue` | `/api/system/dept/*` + `tree` | 树形结构，删除校验下级 |
| 字典管理 | `system/dict/index.vue` | `/api/system/dict/type/*`、`/api/system/dict/data/*` + `all` | 类型 + 字典项，前端缓存 |
| 参数配置 | `system/config/index.vue` | `/api/system/config/*` | 系统参数键值 |

| 登录日志 | `system/loginlog/index.vue` | `/api/system/loginlog/*` + `clear` | 登录成功/失败记录 |

> 权限前缀：`system:user:*`、`system:role:*`、`system:menu:*`、`system:dept:*`、`system:dict:*`、`system:config:*`、`system:operlog:*`、`system:loginlog:*`。

## 4. 代码生成器

后端 `apps/gen`，接口前缀 `/api/gen/`。

| 能力 | 接口 | 说明 |
|---|---|---|
| 读取数据库表 | `GET /api/gen/db/tables` | 查询 `information_schema` |
| 导入表 | `POST /api/gen/db/import` | 写入 `sys_gen_table` / `sys_gen_table_column` |
| 配置列表 | `GET /api/gen/table/list` | 分页 |
| 新建/编辑/删除 | `/api/gen/table/create`、`update/<pk>`、`delete` | 字段级配置 |

| 查看 DDL | `GET /api/gen/table/<pk>/ddl` | 建表语句 |
| 下载 ZIP | `GET /api/gen/table/<pk>/download` | 含 `README-部署说明.txt` |

生成模块具备：标准 CRUD、条件查询、分页、批量删除、Excel 模板下载、批量导入（错误行提示）、条件导出（`apps/student` 为示例）。

## 5. 工作流审批

后端 `apps/workflow`，接口前缀 `/api/wf/`，共 11 张 `wf_` 表。

| 功能块 | 页面 | 能力 |
|---|---|---|
| 流程管理 | `workflow/category|model|form|group|listener|expression` | 分类、BPMN 模型（bpmn-js 设计器）、自定义表单、用户分组、监听器、表达式 |
| 审批中心 | `workflow/instance|task|cc` | 发起流程、我的流程（撤回/终止）、待办（同意/驳回/转审/加签/退回）、已办、抄送我的 |
| OA 示例 | `workflow/leave` | 请假申请演示；请假超过 3 天自动加签总监 |

接口（真实路由）：

```
GET    /api/wf/instance/list            我的/全部实例
GET    /api/wf/instance/my              我发起的
POST   /api/wf/instance/start           发起
GET    /api/wf/instance/detail/<pk>     详情
GET    /api/wf/instance/trace/<pk>      轨迹
POST   /api/wf/instance/terminate/<pk>  终止
POST   /api/wf/instance/withdraw/<pk>   撤回
GET    /api/wf/task/todo                待办
GET    /api/wf/task/done                已办
PUT    /api/wf/task/approve/<pk>        同意
PUT    /api/wf/task/reject/<pk>         驳回
PUT    /api/wf/task/transfer/<pk>       转审
PUT    /api/wf/task/addsign/<pk>        加签
PUT    /api/wf/task/back/<pk>           退回
GET    /api/wf/cc/mine                  抄送我的
POST   /api/wf/cc/read/<pk>             标记已读
GET    /api/wf/option/{users|roles|depts|groups}  审批人选项
```

引擎能力：自研 Python BPMN 解析；串行 / 或签 / 会签；排他/并行网关；审批人支持用户、角色、部门、用户分组、表达式；实例创建时写入 `model_version`，运行中实例不受新版本影响。

## 6. 附加业务模块（7 个）

| 模块 | 接口前缀 | 页面 | 真实实现要点 |
|---|---|---|---|
| 附件管理 | `/api/file/` | `file/index.vue` | 多文件上传保存到 `uploads/YYYYMM/`，MD5 去重；回收站恢复/彻底删除；`preview_url` 返回 kkFileView 地址（服务地址写死 `localhost:8012`），`office_url` 返回占位地址 |

| 定时任务 | `/api/task/` | `task/{info,log}` | CRON/间隔配置、启停、手动触发；`run_once` 写日志 `手动触发（演示：未实际调度）`，未部署 Celery |
| 报表管理 | `/api/rp/` | `rp/{category,datasource,template,gen}` | MySQL/API 双数据源配置、模板预览、手动生成并落生成记录；生成结果为渲染数据，不产出 Excel/PDF 文件 |

| 外部对接 | `/api/outer/` | `outer/{api,log,sync}` | 接口配置（方法/鉴权/请求头）、连通性测试、调用日志；同步任务触发为演示占位 |

## 9. 系统首页 Dashboard

- 页面：`frontend/src/views/dashboard/index.vue`，15 个真实数据面板。
- 接口：`GET /api/home/overview/`、`GET /api/home/rich/`、`GET /api/home/monitor/`（`apps/home`，无数据表，仅聚合）。
- 内容：Hero 问候 + 4 指标卡（待办/未读消息/运行中流程/今日新增用户）+ 趋势 + 待办 + 公告/消息/工作流 + 系统监控/文件/定时任务 + 告警/报表 BI/知识库 + 今日日程 + 用户组织 + 分组常用功能。

### 10.3 渲染与主题

- `SceneViewer` 按需加载 three.js，生成机柜/服务器/空调/UPS/密集架等占位几何；
- 支持对象增删、属性编辑、视角漫游、点击拾取；
- 数据绑定支持表字段/API 双数据源与阈值配色；
- 告警规则 → 记录 → 确认闭环；巡检路线按点位漫游并生成记录；
- 明暗模式与 5 套主题色全部走 CSS 令牌，无硬编码颜色。

## 12. 权限模型与数据约定

### 12.1 权限

- 登录返回 `perms` 与 `menus`；前端动态注册路由，未授权菜单不下发；
- 按钮级权限 `v-perm="'system:user:create'"`；
- 后端每个 ViewSet 声明 `perm_prefix`，由 `PermissionCheck` 校验；`admin` 角色拥有 `*:*:*`；
- 菜单类型：`M` 目录、`C` 页面、`F` 按钮。

### 12.2 数据约定

| 约定 | 说明 |
|---|---|
| 主键 | 雪花算法 `BIGINT`，后端 `common/snowflake.py`，前端以字符串接收 |
| 逻辑删除 | 所有业务表 `is_deleted`，查询默认过滤 |
| 审计字段 | `create_by/create_time/update_by/update_time` |
| 列表序号 | 第一列为分页内序号，不展示主键 |
| 时间格式 | `YYYY-MM-DD HH:mm:ss`（`USE_TZ=False`） |
| 分页 | 默认每页 10 条，参数 `page` / `page_size` |

## 13. 实现状态与边界说明

以下能力在当前仓库中是**配置/演示级**，文档与界面按实际状态描述，不把它当成已部署的完整基础设施：

| 能力 | 实际状态 | 影响 |
|---|---|---|
| 定时调度 | `task_sched` 仅维护任务与日志，手动触发写演示日志；未引入 Celery/Redis | 不会按 CRON 自动执行 |
| 消息推送 | 站内消息真实落库；短信/邮件/Webhook 仅渠道配置 | 无真实外发 |
| 外部同步 | 接口配置与日志真实；`run_once` 返回「演示：未实际拉取」 | 不自动拉取数据 |
| 数据备份 | 手动备份写入模拟成功记录 | 未执行 mysqldump |
| 文件预览 | 返回 kkFileView 地址（固定 `localhost:8012`）；OnlyOffice 为占位 URL | 需外部服务才能预览 |
| 报表生成 | 返回渲染数据并落生成记录 | 不产出 Excel/PDF 文件 |
| 对象存储 | `file.storage.type` 配置项存在，代码未接入 MinIO SDK | 实际仅本地磁盘 |
| 监控采集 | 告警规则/记录真实；无后台采集进程 | 需外部写入告警记录 |

> 上述边界不影响平台、工作流、附件上传、3D、首页等核心功能的真实可用性；如需补齐，见 [开发路线图](./10-开发路线图.md)。
