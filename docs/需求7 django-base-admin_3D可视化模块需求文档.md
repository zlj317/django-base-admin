## 0. 文档说明

本文档定义 `django-base-admin` 系统的 **3D 可视化 / 数字孪生模块**需求。前端使用 Three.js 在浏览器 WebGL 渲染三维场景，Django 后端负责模型资源存储、场景配置、业务数据下发、权限控制与实时推送。模块化设计，与既有后台完全融合，复用菜单、权限、登录、附件、报表、审批、消息体系。

**设计原则**
1. **前后端分离**：Django 只做数据与资源分发，3D 渲染全部在浏览器完成，后端无渲染压力；
2. **组件复用**：模型资源复用附件管理（MinIO），权限复用 RBAC，实时数据复用 Channels/Redis；
3. **可视化配置**：场景、模型摆放、数据绑定尽量通过页面配置完成，减少代码开发；
4. **性能优先**：LOD、实例化渲染、按需加载，保障海量模型场景流畅；
5. **国产化适配**：兼容银河麒麟 + 国产浏览器 WebGL 环境。

## 1. 模块概述

3D 可视化管理面向**机房/机柜、楼宇园区、设备台账、生产线、仓储库房、档案库房、资产可视化**等场景：以三维场景承载业务对象，通过实时数据驱动设备状态、告警、热力、流向，并提供点击交互、下钻详情、关联报表、发起审批等能力，实现业务数据的空间化、可视化表达。

**区别于报表大屏**：报表大屏为 2D 图表看板；本模块为三维空间场景 + 数据绑定 + 交互下钻。

## 2. 菜单结构

```
3D可视化管理（一级菜单）
├── 场景管理        # 场景列表、新建、复制、发布、停用
├── 场景编辑器      # 三维可视化编辑器（摆放模型、设置材质灯光、绑定数据）
├── 模型资源库      # 3D模型(glb/gltf)、贴图、材质资源管理
├── 数据绑定        # 设备点位与业务数据/接口绑定
├── 告警可视化      # 告警规则、告警效果配置
├── 巡检路线        # 三维漫游/巡检路径配置与播放
├── 场景发布        # 场景分享、嵌入大屏、访问记录
└── 3D大屏          # 3D场景与2D图表融合的可视化大屏页面
```

> 遵循全局菜单层级缩进规范：二级菜单在父级基础上右移，三级菜单继续右移。

## 3. 功能需求详细设计

### 3.1 场景管理

| 功能 | 说明 |
| --- | --- |
| 场景列表 | 分页展示全部 3D 场景：场景名称、分类、缩略图、状态（草稿/已发布/停用）、创建人、更新时间、操作（编辑/复制/发布/删除） |
| 新建场景 | 创建空白场景，配置名称、分类、背景、初始相机视角、环境光 |
| 场景分类 | 按业务归类：机房、楼宇、产线、库房、园区、其他 |
| 场景模板 | 内置空白模板、机房模板、楼宇模板，新建时可选模板快速起步 |
| 复制场景 | 一键复制已有场景（含模型与绑定配置），便于批量衍生 |
| 发布/停用 | 草稿发布为可用场景；停用后不可访问但保留数据 |
| 场景缩略图 | 保存时自动截取当前视图快照作为列表缩略图（存附件管理） |
| 场景版本 | 每次编辑保存生成版本快照，支持版本回滚（见 3.9） |
| 场景删除 | 软删除，二次确认，记录操作日志 |

### 3.2 场景编辑器（核心）

基于 Three.js 的可视化编辑器，所见即所得配置三维场景。

**3.2.1 基础编辑能力**
- 模型导入摆放：从模型资源库拖入 glb/gltf 模型到画布，支持位置、旋转、缩放；
- 变换操作：拖拽移动、旋转手柄、缩放轴（TransformControls）；
- 层级管理：对象树展示场景内所有对象，支持分组、重命名、显隐、锁定；
- 多选、框选、对齐、网格吸附；
- 撤销 / 重做。

**3.2.2 环境与渲染**
- 环境光、平行光、点光源、聚光灯配置，光照强度/颜色；
- 天空盒、地面网格、背景色、雾效；
- 材质编辑：颜色、金属度、粗糙度、透明度、贴图切换；
- 相机视角：透视/正交相机，保存命名视角（如"全景""机柜特写"），可切换；
- 后处理效果：辉光、抗锯齿、阴影（可选开关）。

**3.2.3 标注与元素**
- 文字标签（设备名、编号），支持 3D 空间锚定、始终面向相机；
- 图标标记（告警、在线、离线状态标记）；
- 2D 面板（HTML/CSS 叠加层，展示指标、按钮）；
- 引导线、区域高亮、地面网格划分；
- 场景内嵌视频/图片贴图（如设备实时画面）。

**3.2.4 交互配置**
- 对象点击事件配置：弹出信息面板、跳转链接、下钻子场景、打开报表、发起审批；
- 悬停高亮、选中描边；
- 双击聚焦、右键菜单。

**3.2.5 保存与预览**
- 保存场景 JSON（对象树、变换、材质、相机、交互配置）到数据库；
- 预览模式（只读渲染，不含编辑控件）；
- 导出场景配置 JSON（备份/迁移）。

### 3.3 模型资源库

| 功能 | 说明 |
| --- | --- |
| 模型上传 | 支持 glb / gltf（含 .bin、贴图打包 zip），复用附件管理上传能力（分片、断点续传） |
| 资源分类 | 模型、贴图、材质、环境贴图（HDR）分类管理 |
| 模型预览 | 列表中缩略图预览，点击用 Three.js 加载预览旋转查看 |
| 模型信息 | 名称、分类、文件大小、三角面数、贴图数、上传人、上传时间 |
| 格式优化 | 支持 glTF → glb 压缩（可选 gltf-pipeline 预处理），超大模型提示 LOD |
| 存储 | 存 MinIO 对象存储，返回访问 URL |
| 版本/替换 | 同名模型可替换更新，保留历史版本 |

### 3.4 数据绑定（数字孪生核心）

将三维对象与业务数据、实时接口绑定，实现数据驱动场景。

| 功能 | 说明 |
| --- | --- |
| 数据源类型 | 内部数据表（设备台账、报表）、外部接口（数据同步/外部对接模块配置的API）、实时消息（Channels/WebSocket） |
| 绑定对象 | 选择场景内对象，绑定数据源字段（如温度、负载、状态、告警等级） |
| 显示映射 | 数据 → 视觉映射规则：数值映射颜色渐变、状态映射模型切换/显隐、数值映射标签文本 |
| 阈值告警 | 数值超过阈值触发颜色闪烁/图标告警 |
| 刷新频率 | 手动刷新、定时轮询（可配秒数）、WebSocket 实时推送 |
| 绑定生效 | 仅预览/发布模式生效，编辑模式可选是否实时预览 |
| 绑定预览 | 编辑器内可实时查看数据驱动的效果 |

**支持的数据强烈场景**：
1. 设备状态（在线/离线/故障 → 绿/灰/红）；
2. 数值型（温度、负载、库存量 → 颜色渐变 + 标签显示）；
3. 告警等级（提示/警告/严重 → 闪烁频率、颜色、图标）；
4. 流向/流向动画（数据流量、物流动线）；
5. 热力分布（区域热力图着色）。

### 3.5 告警可视化

| 功能 | 说明 |
| --- | --- |
| 告警规则 | 基于数据绑定配置的阈值规则（≥/≤/区间、告警级别） |
| 视觉表现 | 对象闪光、变色、脉冲光晕、告警图标悬浮、声光模拟 |
| 告警面板 | 场景右侧/底部告警列表，点击定位到对应三维对象（相机飞行聚焦） |
| 告警联动 | 推送消息中心；可一键对告警对象发起工单/审批（联动工单、SpiffWorkflow） |
| 告警统计 | 场景内告警数量、级别分布实时统计 |
| 静音/确认 | 告警确认已处理，标记状态，避免重复闪烁 |

### 3.6 巡检路线 / 三维漫游

| 功能 | 说明 |
| --- | --- |
| 路线绘制 | 在场景内绘制巡检路径点，串成路线 |
| 视角跟随 | 相机沿路线自动漫游，可调速、暂停、正放/倒放 |
| 路线信息 | 每个路径点可绑定说明、设备、指标 |
| 巡检记录 | 记录巡检开始/结束时间、执行人、路线、发现异常 |
| 自动巡检 | 结合定时任务，定时自动播放巡检并记录 |
| 手动漫游 | WASD 键盘 + 鼠标自由漫游（第一人称/飞行） |

### 3.7 场景发布与访问

| 功能 | 说明 |
| --- | --- |
| 分享链接 | 生成场景访问链接，可设访问密码、有效期 |
| 权限控制 | 按角色/部门控制哪些人可访问、只读/可交互 |
| 嵌入大屏 | 提供 iframe 嵌入地址，供报表大屏 / 独立门户嵌入 |
| 访问记录 | 记录访问人、IP、时间、停留时长 |
| 访问统计 | 访问量、访问用户分布 |

### 3.8 3D 大屏（场景 + 图表融合）

- 三维场景为主视觉区，四周叠加 2D 指标卡片、图表、告警列表；
- 支持全屏播放、自动轮播切换相机视角；
- 图表数据复用报表/统计接口；
- 大屏布局可配置（场景区与图表区比例、模块显隐）；
- 支持快照导出、定时截图归档到附件管理。

### 3.9 场景版本管理

- 每次保存生成版本快照（场景 JSON）；
- 版本列表、版本对比（对象增删、属性变化）、一键回滚；
- 发布版本独立锁定，编辑不影响已发布版本。

### 3.10 性能与渲染优化

| 优化项 | 说明 |
| --- | --- |
| LOD | 远近模型分级加载，远距离低模 |
| 实例化渲染 | 相同模型批量 InstancedMesh |
| 按需加载 | 分区域/分楼层加载，进入视野才加载 |
| 纹理压缩 | 贴图压缩、KTX2 格式 |
| 帧率控制 | 显示 FPS，低性能设备自动降级（关闭阴影/后处理） |
| 资源缓存 | 模型本地缓存，避免重复下载 |

## 8. 风险与备注

1. Three.js 为浏览器渲染，**Django 不做 3D 渲染**，无后端 GPU 压力，但需关注客户端设备性能；
2. 大模型资源（上百 MB）加载慢，须配合 LOD、压缩、按需加载；
3. 国产浏览器 WebGL 兼容需实测，部分老旧环境仅软渲染，效果与流畅度受限；
4. 场景编辑器开发量大，建议一期先落「场景查看 + 数据绑定 + 告警可视化」，二期再做完整编辑器；
5. 实时数据推送依赖 Redis + Channels，需保证 WebSocket 链路稳定与断线重连。

## 9. 需求摘要（文档头部速览）

> 本模块基于 Three.js + Vue3 前端渲染、Django 后端数据与资源分发，提供 3D 可视化 / 数字孪生能力：场景管理与可视化编辑器（模型摆放、材质灯光、相机视角、标注、交互配置）、模型资源库（glb/gltf 存 MinIO）、数据绑定（业务表/外部接口/WebSocket 实时数据驱动设备状态与视觉映射）、告警可视化（阈值闪烁、光晕、告警定位与确认）、巡检路线三维漫游、场景发布分享与权限访问、3D 大屏（三维场景融合 2D 图表）、场景版本管理与回滚、性能 LOD 优化。与 RBAC、附件管理、报表大屏、工作流审批、工单、消息中心、定时任务深度联动，实现业务数据的空间化可视化表达。

## 10. 业务规则与验收标准（需求补充）

> 本章不含任何技术实现，只描述业务规则、判定逻辑、页面状态差异与验收口径，供产品评审、测试用例设计使用。

### 10.1 数据绑定业务规则

| 规则项 | 需求描述 |
| --- | --- |
| 支持的数据源 | ①内部业务表（设备台账、机房环境、库房环境、工单数量等已授权表）②外部接口（数据同步模块中已配置的 API）③WebSocket 实时通道 |
| 允许绑定的数据表范围 | 由系统管理员在后台维护「可绑定表白名单」，仅白名单内的表可被选择；未在白名单中的表不出现在下拉列表 |
| 允许绑定的字段范围 | 数值型（温度、湿度、负载、负载率）与状态型（运行状态、在线状态、工单数）字段；文本/大字段不允许绑定 |
| 数据安全要求 | 页面只允许选择表与字段，**不允许用户直接输入 SQL 语句或条件表达式**；取数条件由系统按预设模板拼接 |
| 一个对象可绑定数量 | 单个对象最多绑定 3 个字段（主状态 + 辅助数值 + 计数），超出需另行拆分对象 |
| 刷新策略 | 支持手动刷新、定时刷新（最小 5 秒，默认 30 秒）、WebSocket 实时推送；同一场景内以最小间隔统一调度，不允许每个绑定各自起定时器 |
| 取数失败处理 | 单个绑定取数失败不影响其他对象渲染，失败对象显示灰色「离线」并标注「数据获取失败」，连续 3 次失败推送一次消息中心告警 |
| 数据新鲜度 | 页面需展示「数据更新时间」，超过 2 倍刷新周期未更新时，对象标记为「数据过期」（半透明显示） |

### 10.2 告警判定业务规则

| 规则项 | 需求描述 |
| --- | --- |
| 比较符 | 支持 `>=`、`<=`、`>`、`<`、`=`、`between`（区间）六种 |
| 阈值格式 | 单值（如 28）或区间（如 28,32）；非数值状态字段（如「故障」）用 `=` 精确匹配文本 |
| 告警级别 | 1 提示、2 警告、3 严重（红 + 脉冲 + 可选音效） |
| 告警触发动作 | ①对象变色 + 发光/闪烁 ②3D 标签文字变为「对象名 + 告警」 ③写入告警记录表 ④按通知渠道推送站内信/消息中心 |
| 闪烁时长 | 单次告警视觉闪烁持续 6 秒后自动停止，避免视觉疲劳与性能占用；点击告警项可再次触发定位与闪烁 |
| 告警去重 | 同一对象 + 同一规则在 10 分钟内只生成 1 条告警记录，避免刷屏；级别升级（警告→严重）时可立即再次生成 |
| 告警确认 | 运维人员在告警列表点击「确认」，记录确认人与确认时间；未确认告警在大屏顶部常驻显示 |
| 告警处置闭环 | 告警项支持「一键发起工单」「一键发起整改审批」，处置结果（工单完成/审批通过）回写至 3D 对象，对象恢复绿色 |
| 告警历史 | 支持按场景、级别、时间范围、确认状态筛选，保留期与操作日志一致（默认 180 天） |

### 10.3 场景版本与发布规则

| 规则项 | 需求描述 |
| --- | --- |
| 版本生成时机 | 每次点击「保存」自动生成一条版本快照（含全量场景配置），无需人工建版本 |
| 版本说明 | 保存时可填写版本备注（如「增加空调模型」「完善告警规则」），未填写则默认「保存场景」 |
| 发布前置校验 | ①场景配置不为空 ②场景内至少有 1 个有效对象 ③所有对象的模型文件可访问 ④数据绑定配置无语法错误 |
| 发布后限制 | 已发布场景不允许直接删除，须先「下线」；已发布场景的编辑需生成新版本，不影响线上展示 |
| 回滚规则 | 可选择任意历史版本回滚；回滚本身也生成一个新版本（记录「回滚自 Vx」），保证操作可追溯 |
| 版本保留策略 | 默认保留最近 50 个版本 + 最近 180 天；超期版本由定时任务归档，不物理删除 |
| 并发编辑 | 同一场景同一时间只允许一人进入编辑模式，第二人进入时提示「场景正在被 XXX 编辑」，可申请强制接管（记录日志） |

### 10.4 场景权限规则

| 权限级别 | 能力范围 | 典型授予对象 |
| --- | --- | --- |
| 只读查看（read） | 浏览三维场景、切换视角、查看标签与数据、不可点击交互下钻、不可保存 | 普通员工、外部访客 |
| 可交互（interact） | 只读能力 + 点击对象弹面板、查看关联报表、查看历史告警、播放巡检漫游 | 运维人员、档案管理员 |
| 可编辑（edit） | 可交互能力 + 进入编辑器、保存、发布、配置绑定与告警、管理巡检路线 | 系统管理员、场景负责人 |

| 规则项 | 需求描述 |
| --- | --- |
| 授权维度 | 支持按角色、按部门、按全员三种范围；同一场景可叠加多条授权，取最高权限 |
| 默认策略 | 未配置任何授权的场景，默认仅创建人与其所属部门可见；不做「默认全员可见」 |
| 分享链接 | 生成带随机令牌的分享链接，令牌有效期可设（默认 7 天，最长 30 天）；分享链接仅授予只读能力 |
| iframe 嵌入 | 大屏/门户嵌入时校验来源白名单，避免被外部站点盗用 |
| 越权提示 | 无权限访问时提示「无权访问该场景，请联系管理员授权」，并记录访问失败日志 |

### 10.6 性能与验收标准

| 验收项 | 标准 | 验收方式 |
| --- | --- | --- |
| 首屏加载 | 500 对象以内的场景 ≤ 5 秒（局域网环境） | 浏览器性能面板实测 |
| 渲染帧率 | 机房标准场景 ≥ 30fps；低于 20fps 自动降级（关阴影、降像素比） | 帧率监测面板 |
| 单模型大小 | ≤ 50MB，超限拒绝上传并提示压缩 | 上传时校验 |
| 模型三角面 | 单模型建议 ≤ 30 万面，超限提示优化 | 上传后自动统计 |
| 内存占用 | 切换场景后显存回落到基线 ±10% | 任务管理器观察 |
| 标签数量 | 同屏可见标签 ≤ 200，超出按距离/选中动态显示 | 场景实测 |
| 数据推送 | 推送间隔 30 秒，断线 3 秒内自动重连，重连后补齐最新快照 | 断网测试 |
| 告警响应 | 数据超阈值到画面告警 ≤ 2 秒 | 造数测试 |
| 并发访问 | 单场景支持 ≥ 50 人同时只读查看 | 压测 |
| 兼容性 | Chrome / Edge / 360 兼容模式 / 奇安信浏览器 正常渲染 WebGL | 实机验证（含银河麒麟环境） |
| 权限 | 无权限用户无法通过接口或链接绕过 | 越权测试 |

### 10.7 接口与交互约定（需求层面）

| 约定项 | 要求 |
| --- | --- |
| 返回结构 | 统一 `{code, msg, data}`，code=0 成功；失败需返回可读中文原因 |
| 鉴权 | 所有接口需登录态；场景相关接口额外做场景权限校验；接口权限标识挂到 RBAC 按钮权限 |
| 分页 | 列表接口统一 `page`、`page_size` 参数，返回 `total` 与 `list` |
| 幂等 | 保存、发布、告警确认接口需支持重复提交不产生重复数据 |
| 超时 | 场景详情、模型列表接口超时 15 秒；模型上传单独放宽至 5 分钟 |
| 错误提示 | 前端对失败场景给出明确操作建议（如「模型文件过大，请压缩后重试」） |
| 操作日志 | 保存、发布、回滚、删除、权限变更、导出快照均写操作日志（sys_oper_log） |

### 10.8 异常与边界场景需求

| 场景 | 期望表现 |
| --- | --- |
| 模型文件丢失/损坏 | 该对象显示为占位方块并标注「模型缺失」，不影响其他对象；提示管理员重新上传 |
| 场景配置 JSON 解析失败 | 进入兜底空场景 + 错误提示，提供「回滚到上一版本」入口 |
| WebSocket 长时间断开 | 顶部提示「实时数据连接中断，正在重连」，期间数据标记为过期 |
| 浏览器不支持 WebGL | 展示提示页「当前浏览器不支持 3D 渲染，请使用 Chrome/Edge 或开启硬件加速」，并提供 2D 降级视图入口 |
| 大屏长时间运行 | 连续运行 24 小时内存增长 ≤ 15%，支持定时自动刷新页面（可配置，默认关闭） |
| 设备已被删除但场景仍引用 | 对象显示灰色「已停用」，标签提示「设备已删除」，不阻断场景加载 |
