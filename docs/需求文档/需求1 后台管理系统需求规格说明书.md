## 1. 项目概述

### 1.1 背景与目标

参考开源宇道后台管理系统的**架构设计、数据表结构、权限模型与交互范式**，搭建一套前后端分离的后台管理平台。平台内置**代码生成器**作为核心功能：开发人员在页面中录入/选择数据库表信息，配置字段属性、表单控件与查询条件，系统自动生成该表对应的全套业务代码（后端 DRF 接口 + Vue 前端页面），开箱即用，大幅减少重复 CRUD 开发工作量。

适用范围覆盖：内部基础主数据管理、业务台账管理、配置类管理页面快速开发等管理类表单、列表、档案类数据维护场景。

### 1.2 设计原则

1. **对标宇道后台**：沿用经典 RBAC 权限模型、菜单管理、数据字典、部门用户、操作日志等基础模块表结构；
2. **前后端完全分离**：Django 仅输出 RESTful 接口，Vue 负责页面渲染与交互；
3. **先搭框架、后实现业务**：实施阶段**优先搭建项目整体框架并初始化数据库与系统数据表**，框架就绪后再迭代开发业务功能与代码生成器；
4. **生成产物可二次编辑**：生成的代码独立存在，支持开发者手动修改，生成器不强制覆盖；
5. **统一规范**：接口返回格式、分页、导入导出模板、异常返回全平台统一；
6. **可扩展**：预留字段权限、数据权限、工作流、附件上传等扩展点。

### 1.3 项目范围

| 范围 | 内容 |
| --- | --- |
| 平台基础模块 | 固定内置，参考宇道后台原生模块，不通过代码生成器生成 |
| 代码生成器模块 | 本系统核心，可视化配置 + 一键生成 |
| 生成产出能力 | 每张数据表生成后自带的增删改查、分页、导入导出等能力 |

## 2. 总体功能架构

系统划分为三大块：

1. **平台基础模块（固定内置）**
   - 用户管理、角色管理、菜单管理、部门管理
   - 数据字典、字典项管理
   - 操作日志、登录日志
   - 附件上传、文件管理
   - 系统参数配置

2. **代码生成器模块（核心能力）**
   - 数据库表读取、表信息预览
   - 字段可视化配置（字段类型、表单控件、是否查询、是否列表展示、是否必填、导出字段等）
   - 生成参数配置（模块名称、接口前缀、路由地址、父级菜单）
   - 一键生成后端代码、前端代码
   - 代码在线预览、代码包下载

3. **代码生成产出能力（每张数据表自带）**
   - 列表分页查询、条件筛选查询
   - 新增、编辑、删除（单删 / 批量删除）
   - Excel 导入、Excel 导出
   - 详情查看接口
   - 接口自动接入平台 RBAC 权限控制

## 3. 数据库预置说明

> 本章为实施前置要求，按「先搭框架、后实现业务」的顺序，**在开发框架之前先完成数据库的创建与系统表初始化**。

### 3.1 预置操作要求

1. 开发人员使用 `192.168.0.76:3306`、账号 `root`、密码 `root` 连接本地 MySQL 实例；
2. **开发人员自行创建项目数据库**（库名示例：`gen_admin`），使用 `utf8mb4` 字符集；
3. 在已创建的数据库中，**手动执行建表 SQL，一次性创建全部系统基础数据表**（以 `sys_` 开头的表，详见 7.2 基础系统表清单，含 `sys_gen_table`、`sys_gen_table_column`）；
4. 代码生成器**默认不自动执行 DDL 建表语句**：后续业务数据表由开发人员提前在该库中手动建好，再进入生成器页面选择表进行配置与代码生成；
5. Django 项目配置文件绑定该数据库实例的连接信息（见 3.2）。

### 3.2 Django 数据库配置参考（settings.py）

```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': 'gen_admin',          # 自行创建的数据库名
        'USER': 'root',
        'PASSWORD': 'root',
        'HOST': '192.168.0.76',
        'PORT': '3306',
        'OPTIONS': {
            'charset': 'utf8mb4'
        }
    }
}
```

> **认证插件说明**：MySQL 8.0.21 默认使用 `caching_sha2_password` 认证。若 Django 连接报认证错误，在 `192.168.0.76` 数据库实例中执行以下 SQL 调整账号认证方式：
```sql
ALTER USER 'root'@'%' IDENTIFIED WITH mysql_native_password BY 'root';
FLUSH PRIVILEGES;
```

### 3.3 数据库对象约定

| 对象 | 约定 |
| --- | --- |
| 业务数据库名 | 开发人员自行创建，示例 `gen_admin` |
| 字符集 / 排序规则 | utf8mb4 / utf8mb4_general_ci |
| 系统基础表 | 以 `sys_` 前缀命名，初始化时一次性创建 |
| 业务表 | 代码生成产出表，由开发人员提前手动建好 |
| 逻辑删除 | 所有业务表统一携带 `is_deleted` 字段 |

## 5. 【核心需求】代码生成器模块

### 5.1 数据表来源

支持两种模式：

| 模式 | 说明 |
| --- | --- |
| 模式一：读取已有表 | 从当前连接的 MySQL 数据库读取已存在的数据表，自动解析表注释、字段名、字段类型、字段注释、主键、是否允许为空 |
| 模式二：手动新建配置 | 手动新建表配置（不自动建表，由开发人员提前建好 MySQL 表），适合提前设计好表结构的场景 |

> **约束**：代码生成器默认不自动执行 DDL 建表语句，避免误操作；如需建表脚本，可附加生成建表 SQL 文本供人工确认执行。

### 5.2 表与字段可视化配置

选中一张数据表后，进入字段配置表单，每条字段可配置以下属性：

| 配置项 | 说明 |
| --- | --- |
| 字段名称 | 数据库原始字段，只读 |
| 字段注释 | 用作列表表头、表单 label |
| 字段类型 | int / varchar / datetime / decimal 等，自动识别，可微调 |
| 表单控件 | 输入框、数字框、日期选择器、下拉字典、单选、多行文本、文件上传、图片上传 |
| 是否在列表展示 | 勾选则在 Vue 列表页面显示该列 |
| 是否查询条件 | 勾选则在顶部查询栏生成查询项，支持配置查询方式（等于/模糊/大于/小于/区间） |
| 是否必填 | 新增/编辑表单校验规则 |
| 是否导出字段 | 是否放到导出 Excel 列中 |
| 是否导入字段 | 是否支持从 Excel 导入回写 |
| 排序号 | 控制表单、列表展示顺序 |
| 字典编码 | 绑定系统字典类型，控件自动渲染下拉 |

同时配置模块基础信息：

| 配置项 | 说明 |
| --- | --- |
| 模块中文名称 | 业务模块展示名称 |
| 模块英文标识 | 如 `student` |
| 接口路由前缀 | 如 `/api/xxx/` |
| 前端页面存放路径 | Vue 页面生成目录 |
| 父级菜单 | 生成后自动创建菜单记录到 sys_menu（可选） |
| 是否开启逻辑删除 | 生成代码自动携带 is_deleted 过滤 |
| 是否开启导入功能 | 总开关 |
| 是否开启导出功能 | 总开关 |

### 5.3 一键生成能力（后端 Django + DRF）

**生成的后端文件清单**

| 文件 | 说明 |
| --- | --- |
| models.py | Django ORM 模型类，包含字段注释、verbose_name |
| serializers.py | 序列化器（新增、详情、列表序列化分开） |
| views.py | DRF 视图集 ViewSet |

| 分页类 | 统一系统分页，返回总条数、当前页、每页条数、数据列表 |
| 过滤类 | 根据配置的查询条件自动生成 filter |

**固定生成的接口清单**

| 接口 | 方法 | 能力 |
| --- | --- | --- |
| /list | GET | 分页列表 + 多条件组合查询 |
| /retrieve | GET | 单条详情 |
| /create | POST | 新增 |
| /update | PUT | 修改 |
| /delete | DELETE | 删除（支持批量 ids） |
| /importTemplate | GET | 下载导入模板 |

### 5.4 一键生成能力（Vue 前端代码）

**生成的 Vue 单文件页面（SFC）**

| 内容 | 说明 |
| --- | --- |
| 列表页面 | 顶部查询表单、查询/重置按钮、新增、导入、导出、批量删除按钮 |
| 表格区域 | 根据字段配置动态渲染列，支持排序 |
| 弹窗表单 | 新增/编辑共用弹窗，自动渲染对应控件、前端表单校验 |
| 详情弹窗 | 记录详情展示 |
| 接口请求 js | axios 请求封装，统一调用后端接口 |

**页面自带交互**：查询、重置、分页切换、每页条数选择、单行编辑/删除、批量勾选删除、导入弹窗与上传、导入错误信息展示、导出当前筛选结果。

### 5.5 代码预览与下载

1. 生成后页面在线分 tab 预览每个文件完整代码；
2. 支持打包 ZIP 下载全部代码；
3. 提供复制单个文件代码功能；
4. 提示部署步骤：如何拷贝到 Django 后端目录、Vue 目录、如何执行数据库迁移、如何添加菜单。

### 5.6 重要约束

1. 代码生成是一次性模板渲染；后续表结构变更重新生成不会自动合并已有修改，需提示开发者注意覆盖风险；
2. 支持预览建表 SQL 语句、提供复制，不会自动执行；
3. 生成的权限标识自动按规则生成，并与 sys_menu 菜单绑定。

## 6. 公共通用能力需求

> 以下能力全平台生效，包括代码生成器生成的业务模块。

1. **登录认证**：JWT Token 认证，前端携带 token，token 过期自动刷新；
2. **逻辑删除统一规范**：所有业务表统一 `is_deleted tinyint(1)`（0 未删 / 1 已删）；查询默认过滤已删除数据；
3. **统一分页返回结构**

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "total": 100,
    "page": 1,
    "page_size": 10,
    "list": []
  }
}
```

4. **导入能力规范**：模板自动包含表头；导入时做字段类型校验、必填校验、唯一性校验；校验失败返回行号 + 错误信息，不导入脏数据；
5. **导出能力规范**：导出内容为当前页面筛选后的结果；支持限制最大导出行数，防止数据库压力；
6. **字典回显**：列表、表单自动翻译字典值；
7. **操作日志自动记录**：新增、编辑、删除、导入、导出自动写入 sys_oper_log；
8. **全局异常捕获**：统一错误码返回。

| sys_gen_table_column | 代码生成字段配置表（存储每张表的字段配置：控件类型、是否查询、是否列表展示等，代码生成器的核心配置表） |

## 9. 业务流程说明

1. 开发人员提前在 MySQL（192.168.0.76:3306）建好业务数据表；
2. 登录后台，打开【代码生成器】菜单；
3. 从数据库列表选择目标数据表；
4. 进入配置页面，设置模块信息，逐个配置字段的表单控件、查询条件、是否导入导出；
5. 保存生成配置（存入 sys_gen_table、sys_gen_table_column）；
6. 点击【生成代码】，系统基于模板渲染 Django 和 Vue 全套代码；
7. 在线预览、下载代码包；
8. 开发者将代码拷贝到后端 Django 项目、Vue 前端项目；
9. 执行 migrate（如有新 model），在菜单管理中分配菜单权限；
10. 刷新页面，即可使用该业务模块的增删改查、导入导出功能。

## 11. 风险与备注

1. 代码生成器只解决标准化 CRUD；复杂业务逻辑（关联校验、跨表事务、特殊计算）仍需开发人员在生成代码基础上手动修改；
2. 数据库字段变更后，需重新进入生成器重新配置并生成代码；
3. 权限体系完全复用平台 RBAC，生成的按钮权限标识自动注册到菜单；
4. 业务数据表必须由开发人员提前在 `192.168.0.76` 数据库中手动创建，代码生成器不自动执行 DDL；
5. 重新生成代码会覆盖原有业务代码，需开发人员自行做好版本管理。
