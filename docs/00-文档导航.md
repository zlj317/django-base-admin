## 项目速览

- 技术栈：Django 4.2 + DRF + MySQL 8；Vue 3 + Vite 5 + Element Plus + vue-router 4 + axios。
- 核心能力：平台基础模块（用户/角色/菜单/部门/字典/配置/日志）+ **代码生成器**（读表 → 配置 → 预览/下载 → 自动注册菜单）+ **工作流审批**（BPMN 2.0 设计、流程发起、待办/已办/抄送、OA 请假示例）+ **附加模块**（附件管理、消息中心、公告通知、定时任务、报表管理、报表大屏、外部对接，共 22 张扩展表）。
- 默认账号：`admin / 123456`（由 `python manage.py init_db` 初始化）。
- 统一约定：HTTP 状态恒 200，业务码在响应体 `code`；JWT 2 小时，剩余 30 分钟静默续期；逻辑删除 `is_deleted`。
