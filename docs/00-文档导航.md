## 项目速览

- 技术栈：Django 4.2 + DRF + MySQL 8；Vue 3 + Vite 5 + Element Plus + vue-router 4 + axios。
- 核心能力：平台基础模块（用户/角色/菜单/部门/字典/配置/日志）+ **代码生成器**（读表 → 配置 → 预览/下载 → 自动注册菜单）+ **工作流审批**（BPMN 2.0 设计、流程发起、待办/已办/抄送、OA 请假示例）+ **附加模块**（附件管理、消息中心、公告通知、定时任务、报表管理、报表大屏、外部对接，共 22 张扩展表）。
- 默认账号：`admin / 123456`（由 `python manage.py init_db` 初始化）。
- 统一约定：HTTP 状态恒 200，业务码在响应体 `code`；JWT 2 小时，剩余 30 分钟静默续期；逻辑删除 `is_deleted`。

## 新增功能模块一览（2026-11-04 批次）

### 后端新增 Django App（12 个）
- apps/sys_no：编码规则（sys_no_rule + sys_no_log）
- apps/imprint：导入模板（imp_template + imp_template_column）+ 打印模板（print_template）
- apps/backup：数据备份（backup_record + backup_strategy）
- apps/dp：数据权限（sys_data_permission + sys_role_data_permission）
- apps/dsm：脱敏规则（desensitize_rule + desensitize_field + desensitize_role）
- apps/mon：监控告警（monitor_alarm_rule + monitor_alarm_record）
- apps/sec：安全策略（sys_ip_control + sys_login_attempt + sys_rate_limit）
- apps/tenant：多租户（sys_tenant + sys_tenant_user + sys_tenant_package）
- apps/wo：工单管理（work_order_type + work_order + work_order_log）
- apps/cal：日历日程（cal_schedule + cal_reminder）
- apps/kb：知识库（kb_category + kb_document + kb_favorite）
- apps/home：首页聚合接口（非完整 CRUD app）

### 前端新增页面（22 个）
- views/dashboard/index.vue（重写工作台首页）
- 各模块列表页：每个至少一个 index.vue，复用统一骨架（app-container + search-card + table-card + pagination-wrap）
- 路由：router 用 import.meta.glob('../views/**/*.vue') 自动扫描

### 数据表（33 张）

- 菜单初始化：init_db.py 已注册 11 个新 app 的 seed_* 调用

- 后端：继承 common/views.py 的 CrudViewSet，配置 model/serializer_class/perm_prefix/filter_map/order_by/module_name
- 前端：el-card(search-card) 查询 + el-card(table-card) 工具栏/表格/分页；分页 layout="total, sizes, prev, pager, next, jumper"
- 列表面板全局样式：index.css 已统一，新页面直接套用 .table-card / .search-card / .pagination-wrap / .toolbar
