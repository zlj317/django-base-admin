## 目录结构

```
docs/
├─ 00-文档导航.md                 # 本文件
├─ 需求文档/                      # 需求 1~7
├─ 项目文档/                      # 功能、启动、中间件、接口、数据库、测试、运维、FAQ、术语、路线图
├─ 架构图/                        # 01~09 独立 SVG
├─ 设计稿或截图/                   # 界面截图、3D 场景截图、首页改版设计
├─ 数据库/                        # 实际库单文件导出（结构 + 数据）与导出说明
├─ 报告/                          # UI 验收、主题优化、前端注释
├─ 功能学习/                      # 面向 Java 开发者的 100 个功能调用示例
├─ 后台管理系统-初始化建表SQL.sql
├─ 后台管理系统-工作流建表SQL.sql
├─ additional_module_init.sql
├─ new_features_init.sql
└─ scene3d_init.sql
```
