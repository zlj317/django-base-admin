## 统计口径

- 覆盖后端 App：24 个（auth 与 system 共用一个 App，另含 home、scene3d、student 等）。
- 涉及数据表：87 张中的绝大多数核心表；未覆盖表在总索引中说明原因。
- 每篇文档统一结构：前端触发位置 → 前端 HTTP 调用 → 路由与视图 → 业务逻辑 → ORM/SQL 与表结构 → 响应封装与消费 → Java 对照提示 → 逐行中文注释。
